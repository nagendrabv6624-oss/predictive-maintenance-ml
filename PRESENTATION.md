# Project 2 — Predictive Maintenance ML

## Problem
Predict machine-failure risk from operating-condition and sensor measurements so maintenance teams can prioritize inspection.

## Dataset
- AI4I 2020 Predictive Maintenance Dataset
- 10,000 simulated industrial records
- Five numeric sensor variables and categorical product type
- Binary target: Machine failure

Source: UCI Machine Learning Repository, DOI 10.24432/C5HS5C.

## Models and validation
- Logistic Regression baseline
- Random Forest classifier
- Prior-probability dummy baseline
- Stratified 80/20 holdout
- Five-fold stratified cross-validation
- Average precision, recall, precision, F1, ROC-AUC and confusion matrix

## Important honesty point
AI4I 2020 is synthetic, as stated by UCI. The project demonstrates a predictive-maintenance ML workflow on a public benchmark; it does not establish real factory performance. Holdout metrics are generated by running the committed training script and are not pre-claimed in this repository.

## Future validation
Test with time-stamped, machine-specific plant data; tune the alert threshold using downtime and false-alarm costs; validate on a later time period before deployment.
